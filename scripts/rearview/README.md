# 대각선 뒤 구도 구속 측정 — 프로토타입 (2026-09-26, Claude)

측면이 아닌 **골대 쪽을 향해 뒤/대각선에서 찍은 영상**용. 공의 겉보기 크기 대신
**골대(알려진 크기)로 카메라 자세를 잡고, 멈춘 공 위치를 시작점으로, 화면 궤적 전체에 3D 물리 궤적을 맞춘다.**

## 흐름
1. 골대 네 모서리(포스트·크로스바 파이프 중심) 픽셀 → `solvePnP`(IPPE) 로 카메라 자세. 초점거리 f 는 골대 재투영 오차가 최소인 값
2. 킥 전 멈춘 공 중심 → 카메라 광선과 z=0.11m 평면 교점 = 3D 시작점 P0
3. 공 추적: `track2.py`(대략 경로 가이드) → `track3.py`(이어서 자동 추적). 흰색+움직임 블롭
4. `fit_trajectory.py`: 초기속도(3)·킥 시각·항력 k·회전(마그누스, 속도에 수직) 를 재투영 오차 최소화로 추정
   골대에 닿는 장면이 있으면 그 시각·위치를 제약으로 추가(05 에서 사용)

## 사용 (클라우드에서 돌린 방식 — 경로는 맞게 고칠 것)
python3 track2.py video guide.json out.json 45
python3 track3.py video out.json out_b.json 14 200
python3 fit_trajectory.py 04 1621        # solve.py 의 goal_img / ball_c 를 클립에 맞게

## 알게 된 것
- 포물선만(항력·회전 없음)으로는 RMS 22 px 로 안 맞는다. **회전(마그누스) 넣어야 1 px 대**
- 가장 큰 오차원은 **초점거리 f**. 속도가 f 에 거의 비례(±200 px → ±10%). 골대만으로는 f 가 ±200 정도로만 잡힌다
- 멈춘 공 크기는 f 와 무관하게 **골대 크기(스케일)** 를 검증한다. 04 에서 공이 예측보다 5~9% 크게 보임 → 골대가 실제 7.32 m 보다 작거나 가장자리 블러
- 04/05 는 Sony RX100 V(줌 렌즈) 촬영 — 폰이 아니라 화각 표를 쓸 수 없다


## 2차 — 경기장 라인으로 카메라 보정 (결과 수정)
골대만으로 잡은 초점거리(1621)가 틀렸다. 골대는 거의 정면이라 초점거리를 잘 못 잡는다.
**페널티 박스 라인(16.5 m)과 페널티 아크(반지름 9.15 m)** 를 골대·키·더미 높이와 함께 맞추면
f = 1373 (RX100 광각 끝 24mm 와 맞는 값), 카메라 높이 1.25 m, 경기장 크기 배율 0.985(표준 규격).

| 클립 | 킥→골라인 | 초속 | 발사각 | 비고 |
|---|---|---|---|---|
| 04 | 20.7 m | **82 km/h** | 21° | 1차 100 km/h → 수정 |
| 05 | 20.6 m | **69 km/h** | 24° | 1차 81 km/h → 수정 |

독립 확인:
- 표준 경기장 라인을 보정된 카메라로 투영하면 실제 흰 선과 겹친다(라인 4 cm, 아크 1.5 cm)
- 키커 182 cm: 예측과 1.6 px(0.5%) 차이
- **05 크로스바 도착**: 제약 없이 푼 궤적이 골라인에서 높이 2.56 m, 시각 3.339 s — 관측(크로스바, 3.337 s)과 일치
  (1차 f=1621 에서는 같은 계산이 1.84 m, 3.476 s 로 어긋났다)
- 더미 175 cm 는 5~8% 작게 측정됨 — 실제 높이·받침 확인 필요

코드: `calibrate_pitch.py`(골대+라인+높이 동시 보정), `fit_with_pitch_pose.py`

## 5차 — 06·07 (키커 키 모름)
- 06 (2018 안드로이드 폰, 30fps, 손으로 들고 킥 따라 패닝, 유소년 키커): 패닝은 골대·컨테이너 쪽 특징점 호모그래피로 기준 프레임(62)에 정합.
  보정 단서가 골대(왼쪽 기둥이 화면 끝)·골라인·더미 4개뿐 → **초점거리가 안 잡힘**(2200~3400 모두 비슷하게 맞음, 2배 망원 추정).
  골키퍼가 킥 1.23 s 뒤 잡는 장면이 있는데, 어떤 초점거리에서도 궤적이 키퍼 위치에 제때 도달하지 못함(도착 제약을 넣어도 7~12σ 어긋남) → 보정이 틀린 것.
  거리÷시간으로만 보면 60~90 km/h — 폭이 커서 **측정 불가로 판정**.
- 07 (2018 니콘, 30fps, 약간 흔들림): 거의 정면 구도 + 공이 골대 위로 높이 떠서 사라짐(도착 사건 없음) + 앞사람들. 03 과 같은 이유로 불안정 → 계산 보류.

### 측정 불가였던 영상 — 더미·공 크기로 추정
- 07 (대학 선수, 정면): 골대 3모서리 + 더미 4개 + 공(5호) 로는 초점거리가 안 정해짐(1000~3000 이 똑같이 맞음).
  골에어리어 라인(5.5 m) 위치로 f 1300~1600, 공~벽 9.15 m 규정을 쓰면 f≈1570.
  공이 크로스바 윗면을 맞고 튀는 장면(1.335 s)을 도착 제약으로 넣어 **85~102 km/h (벽 9.15 m 가정 시 약 100)**, 거리 18.7~22.6 m.
- 06 (유소년, 폰 패닝): 골대를 **유소년 5×2 m** 로 두면 장면이 훨씬 잘 맞음(성인 골대 대비 오차 1/4). 공 4호.
  영상 궤적 전체 맞춤 40~43, 킥→키퍼 캐치(1.28 s) 거리÷시간 44~50 → **약 43~50 km/h**, 거리 12~14 m.
  성인 골대로 가정하면 약 100 km/h 가 나오지만 장면 적합도가 나쁘고 유소년에게 비현실적.
- 03 (학성초, 정면): 더미 160 반영 96~105 km/h. 그러나 공 크기가 더미 기준 예측보다 15% 작게 보임 →
  공이 4호이거나 경기장이 성인 규격이 아닐 가능성. 초등학생 기준으로 높은 값이라 **골대·경기장 규격 확인 전까지 보류**.
